# Instructions

# 指示

Given an age in seconds, calculate how old someone would be on a planet in our Solar System.

给定以秒为单位的年龄，计算某人在太阳系行星上的年龄。

One Earth year equals 365.25 Earth days, or 31,557,600 seconds.
If you were told someone was 1,000,000,000 seconds old, their age would be 31.69 Earth-years.

一个地球年等于 365.25 个地球日，即 31,557,600 秒。
如果告诉你某人的年龄为 1,000,000,000 秒，那么他们的年龄将为 31.69 地球年。

For the other planets, you have to account for their orbital period in Earth Years:

对于其他行星，您必须考虑它们以地球年为单位的轨道周期：

| Planet  | Orbital period in Earth Years |
| ------- | ----------------------------- |
| Mercury | 0.2408467                     |
| Venus   | 0.61519726                    |
| Earth   | 1.0                           |
| Mars    | 1.8808158                     |
| Jupiter | 11.862615                     |
| Saturn  | 29.447498                     |
| Uranus  | 84.016846                     |
| Neptune | 164.79132                     |

~~~~exercism/note
The actual length of one complete orbit of the Earth around the sun is closer to 365.256 days (1 sidereal year).
The Gregorian calendar has, on average, 365.2425 days.
While not entirely accurate, 365.25 is the value used in this exercise.
See [Year on Wikipedia][year] for more ways to measure a year.

~~~~练习/注意事项
地球围绕太阳运行一周的实际长度接近 365.256 天（1 恒星年）。
公历平均有 365.2425 天。
虽然不完全准确，但本练习中使用的值是 365.25。
有关衡量年份的更多方法，请参阅[维基百科上的年份][年份]。

[year]: https://en.wikipedia.org/wiki/Year#Summary
~~~~
